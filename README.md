# Rakta Daan - Login & Registration UI

## Project Description

Rakta Daan is a Flutter mobile application interface developed as part of a Flutter assignment. The project focuses on creating a clean and user-friendly Login and Registration interface using Flutter widgets, layouts, text fields, buttons, navigation, and form validation.

## Features

### Login Page
- Application name and logo
- Email input field
- Password input field
- Show/Hide password functionality
- Login button
- Forgot Password option
- Navigation to Registration Page
- Basic form validation

### Registration Page
- Application name and logo
- Full Name input field
- Email input field
- Password input field
- Confirm Password input field
- Password visibility option
- Create Account button
- Navigation back to Login Page
- Basic form validation
